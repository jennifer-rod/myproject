Proyecto Angular + Firebase

🎯 El Proyecto

PetWorld es una aplicación desarrollada con Angular 17 y desplegada en Firebase Hosting. Fue creado como proyecto académico para demostrar el uso de módulos, rutas y estilos en Angular.

🛠️ Tecnologías

  • ⚡ Angular 17 (Standalone Components)
  • 🔥 Firebase Hosting
  • 🐙 GitHub (Control de versiones)
  • 🎨 CSS personalizado con variables

📦 Módulos

  • 🏠 Home — Página principal
  • 🐱 Cats — Módulo de gatos
  • 🐶 Dog — Módulo de perros
  • 📖 About — Este módulo
